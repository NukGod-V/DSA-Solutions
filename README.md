### Auto-sync LeetCode solutions to this repo:
1. Install **LeetCode GitHub Sync** from Chrome Web Store
2. Go to extension settings → connect your GitHub account
3. Select this repo (`DSA-Solutions`) as the target
4. Set folder structure to match topics above
5. Every accepted solution auto-commits here ✅

- Save your `.py` solution files named as `problem_name.py`
- Place in the correct topic folder
